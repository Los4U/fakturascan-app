# FakturaScan — strona publiczna

Repozytorium zawiera wyłącznie **politykę prywatności** aplikacji FakturaScan, publikowaną
przez GitHub Pages pod adresem <https://los4u.github.io/fakturascan-app/>.

Adres jest wymagany przez Google przy publikacji ekranu zgody OAuth i musi pozostać
osiągalny tak długo, jak aplikacja korzysta z Dysku Google.

**Kod źródłowy aplikacji jest w osobnym, prywatnym repozytorium.** Tutaj nie ma kodu.

## Zmiany

Źródłem prawdy jest plik `docs/POLITYKA_PRYWATNOSCI.md` w repozytorium aplikacji;
`index.html` jest z niego generowany. Każda zmiana treści wymaga podniesienia numeru wersji
i daty obowiązywania w obu miejscach.
